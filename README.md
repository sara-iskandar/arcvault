## ArcVault Intake and Triage Pipeline

AI-powered intake and triage workflow for a fictional company, ArcVault, built in n8n using Groq for classification and enrichment.

Files:
- n8n_workflow.json, the exported n8n workflow
- structured_output.json, processed output for all 8 test messages
- llm_prompts.md, the two prompts used, with reasoning and tradeoffs
- project_architecture.md, system design, routing logic, escalation logic, and production-scale notes
